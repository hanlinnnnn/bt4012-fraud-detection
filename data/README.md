# Data

Put the competition files here (they are not committed):

- `train.csv`: transactions from periods 1–35. `label` is 1 = illicit, 0 = licit, empty = unknown.
- `test.csv`: transactions from periods 36–49. `index` is the submission id.
- `txs_edgelist.csv`: the transaction graph, one directed edge `txId1 -> txId2` per row.
- `sample_submission.csv`
